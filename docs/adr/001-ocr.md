# ADR 001 — PaddleOCR

Status: accepted

PaddleOCR 3.3.2 with the PaddlePaddle 3.2.0 CPU wheel is the OCR provider. It runs locally, returns quadrilaterals, and worked on Python 3.12 in this environment. Tesseract is lighter to install but weaker on rotated lines. EasyOCR would load a second Torch stack beside LaMa. Cloud OCR is out of scope.

The rest of the app sees `RawDetection` values and then normalized regions. Replacing Paddle means a new class, not a frontend change.

Limitation: the default language is English. The first call downloads detection, recognition, and text-line orientation models into `models/paddlex/official_models/`.
