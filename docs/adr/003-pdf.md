# ADR 003 — PyMuPDF, per page

Status: accepted

PyMuPDF both reads text spans and edits them. Native replacement redacts the span (images and line art are kept) and inserts Liberation text at the old baseline. Scanned pages are rendered, OCR'd, inpainted, and on export become a new image page of the same size. Unedited pages are copied through.

Rasterizing the whole file was rejected. A mixed PDF therefore stays mixed: vector pages remain vector.
